このガイドで出てくる文字列は、すべて「Claude デスクトップアプリ」の「Code」タブの入力欄に貼ります。ここを間違えると、何をやってもエラーになります。

Chat Cowork Code
ここに貼る（ふだんの会話をする入力欄）▶

⭕ Claudeアプリ → 上の「Code」に切り替え → 下の入力欄

❌ 黒い画面PowerShell・ターミナル・コマンドプロンプト。この導入手順は黒い画面では動きません。貼ると「用語 …は認識されません」と出ます。
❌ 「Chat」「Cowork」タブ同じアプリでも動きません（この2つは、あなたのパソコンのファイルを触れないため）。必ず「Code」に切り替えてください。

💡 このガイドで貼るのはClaudeへのお願いの文章であって、パソコンへの命令ではありません。黒い画面に貼ると「用語 …は認識されません」と出ます。出てしまった方は、その画面を閉じてアプリに戻れば大丈夫です。

🪟 Windows の方：準備は3つ

上から順に。ここさえ済めば、あとは Mac と同じです。
  1. ① Claude デスクトップアプリを入れて、ログインする 公式ページ → https://claude.com/ja-jp/download
    ダウンロードしたファイルをダブルクリックして「次へ」で進めばOK。ボタンが2つ並んで迷う方は下の折りたたみへ👇
    入れたらアプリを開いて、いつものアカウントでログインしてください。
    ⚠️ 検索から入ると広告枠に偽サイトが混ざります。URLが claude.com か確認してください。
    💳 Claude の有料プラン（Pro など）が必要です。無料プランのままだと「Code」を押したときにアップグレードを求められて、ここから先に進めません。
    ✅ こうなったら成功：アプリが開いてログインでき、画面の上に Chat / Cowork / Code が並んで見える
  2. ② Git を入れる（Windows だけ必須） これが無いと Code タブが開けません（赤字で「ローカルセッションには Git が必要です」と出ます）。裏方のソフトなので、入れたあとに操作することはありません。
    👉 https://git-scm.com/downloads/win を開いて「64-bit Git for Windows Setup」をダウンロード → ダブルクリック → 出てくる画面はすべてそのまま「Next」→ 最後に「Install」。
    ⚠️ 入れ終わったら、Claude アプリをいったん完全に閉じて、開き直してください。これをしないと、Git を入れても赤い警告が消えません（ここで詰まる方がいちばん多いです）。
  3. ③ Chrome 拡張機能「Claude」を入れる 分析スキルが、あなたのChromeでInstagramを見に行くために使います。入れ方は下の折りたたみへ👇（3分）。台本づくり・動画編集だけなら無くても動きます。
💡 Node.js・npm・winget は不要です。アプリの中に Claude Code が入っているので、黒い画面での準備はいりません。

📎 準備の詳しい手順（必要な人だけ開いてください）

🧩 Chrome 拡張機能「Claude」の入れ方（分析スキルを使う方は必須・3分）

競合アカウント分析やバズ企画リサーチは、あなたのChromeでInstagramを開いて画面を読み取るという動き方をします。そのための部品が拡張機能「Claude」です。あなたがログイン済みのInstagramをそのまま見に行くので、新しくID・パスワードを入れる必要はありません。

① Chrome ウェブストアから追加する（下のリンクを開いて「Chromeに追加」→「拡張機能を追加」）

https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn

⚠️ 検索から入ると似た名前の偽物が混ざることがあります。上のリンクから入るのが安全です（提供元が Anthropic になっているか確認してください）。

② 拡張機能にログインする
Chrome右上のパズルのピース🧩をクリック →「Claude」を選び、いつものアカウントでログインしてください。ピン留め（📌）しておくと、次から一発で開けます。

③ Chrome で Instagram にログインしておく
分析スキルは「あなたが見ている状態のInstagram」を読みます。Chromeで instagram.com を開いてログイン済みにしておいてください。

④ 初めて使うときは「許可」を聞かれます
スキルがInstagramを見に行くとき、拡張機能が確認を出します。「許可」を選べばOKです。

💡 Claudeの有料プラン（Pro など）が必要です。うまく動かないときは、Claude Code に「Chrome拡張がつながっているか確認して」と聞くと、状態を調べて直し方を教えてくれます。

🪟 Windows の方：どっちをダウンロードする？（64bit / arm64）

ダウンロードページ（https://claude.com/ja-jp/download）を開くと、Windows だけボタンが2つ並んでいて迷います。結論から言うと 上の「Windows」でOK です。

・「Windows」…市販パソコンのほとんど（Intel／AMD）はこちら。迷ったらこれを選んでください。
・「Windows (arm 64)」…Snapdragon という部品を積んだ一部の機種だけ（Surface Pro X・一部の Copilot+ PC）。

自分がどちらか確かめたいとき：
設定 → システム → バージョン情報 を開き、「システムの種類」を見てください。
・x64 ベース プロセッサ → 「Windows」
・ARM ベース プロセッサ → 「Windows (arm 64)」

💡 もし間違えて入れてしまっても、アプリが起動しないだけでパソコンは壊れません。その場合はもう片方を入れ直せば大丈夫です。

🍺 Homebrew の入れ方（Mac で動画編集を使う方だけ・3分）

Homebrew（ホームブリュー）は、動画編集に必要な部品を自動で入れてくれる道具です。1回入れれば、あとはずっと使えます。

① まず入っているか確認：Mac標準の「ターミナル」アプリを開いて、下を貼って実行。バージョン（例：Homebrew 4.x.x）が出たら導入ずみなので何もしなくてOKです。

brew --version

② command not found と出たら、下を貼って実行（公式のインストーラーです）。

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

途中で Macのログインパスワードを聞かれます。打っても画面には何も表示されませんが、そのまま入力して Enter で進みます。数分かかります。

③ 使えるようにする（この2行を忘れると「入れたのに見つからない」となります）。

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

④ もう一度 brew --version を実行して、バージョンが出れば完了です。

💡 うまくいかないときは、その画面をスクショして Claude Code に貼り、「これどうすればいい？」と聞けば教えてくれます。

❓ うまくいかないとき（症状べつ）

実際に受講生さんがつまずいたところです。上から順に見てください。
「Code」を押すとアップグレードを求められる／Codeタブが開けない

👉 Claude の有料プラン（Pro など）が必要です。無料プランでは Code タブは使えません。契約したあと、アプリをいったん閉じて開き直してください。
「403」や認証のエラーが出るときは、いったんサインアウトして、もう一度サインインし、アプリを完全に終了してから開き直すと直ります。

STEP2 の途中で止まった／「作業フォルダの外です」と言われた

👉 確認に「拒否」を押していませんか。スキルの置き場所は、STEP1 で選んだフォルダの外にあります。もう一度 STEP2 の文章を貼って、出てくる確認はすべて「許可」を押してください。
それでも止まるときは、そのまま「ホームフォルダの .claude/skills に置いてください。許可します」と返信してください。

スキルが22個そろわない／一部しか入っていない

👉 そのまま「足りないので、もう一度やり直してください」と返信すれば入れ直してくれます。数が合ったらアプリを開き直してください。

アプリが開かない（Mac）「開発元を検証できないため開けません」

👉 アプリのアイコンを右クリック →「開く」を選び、出てきた画面でもう一度「開く」を押してください。初回だけ必要な操作です。

「/plugin isn't available in this environment.」と出た
/plugin isn't available in this environment.

👉 /plugin ではじまる2行は、古い手順です。いまのアプリでは使えません。このガイドの STEP2 の文章（日本語のほう）を貼ってください。それで同じスキルが入ります。

「用語 '/plugin' は、コマンドレット…として認識されません」と出た
/plugin : 用語 '/plugin' は、コマンドレット、関数、スクリプト ファイル、 または操作可能なプログラムの名前として認識されません。

👉 黒い画面（PowerShell）に貼っています。その画面は閉じてOKです。Claude アプリを開いて 「Code」タブに切り替え、フォルダを選んでから、下の入力欄に貼り直してください。

「用語 'claude' は…認識されません」と出た
claude : 用語 'claude' は、コマンドレット、関数、スクリプト ファイル、 または操作可能なプログラムの名前として認識されません。 ← Windows zsh: command not found: claude ← Mac

👉 黒い画面でこの作業をする必要はありません。アプリの中に Claude Code が入っています。アプリを開いて「Code」タブから進めてください。Node.js も npm も要りません。

赤字で「ローカルセッションには Git が必要です」が消えない（Windows）

👉 Git を入れたあと、Claude アプリを閉じて開き直しましたか？ Windows は、開いたままのアプリに新しいソフトの情報が伝わりません。タスクバーのアイコンを右クリック →「閉じる」で完全に終了 → もう一度起動してください。それでも消えないときは、パソコンを再起動すると確実です。

貼っても何も起きない／「使えません」と言われる

👉 作業フォルダを選んでいない可能性があります。STEP1 に戻って、「Code」タブで Local → フォルダを選択 を先に済ませてください。入力欄が出ていない状態では、STEP2は動きません。

スキルを入れたのに、名前を呼んでも反応しない

■ デスクトップアプリと、ターミナルの claude は別物です

【Mac の方】「ターミナル」アプリを開いて、下を貼って実行。

■ npm install -g でエラーが出たとき（Windows）
npm で入れようとすると「このシステムではスクリプトの実行が無効になっているため…npm.ps1 を読み込むことができません」と出ることがあります。Windows の初期設定によるものです。上の irm の1行で入れれば、この問題は起きません。どうしても npm で入れたい場合は、先に下を実行してから入れ直してください（この画面の中だけ一時的に許可する、安全な方法です）。

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
