OTOLAB SKILLS ｜ SETUP

おとラボ スキル 導入ガイド

Claude Code に貼るのは 3つ だけ（スキル導入の2行＋初期設定）。分析・台本・動画編集の全スキルが、あなた仕様で使えるようになります。

🧰 はじめる前に

  • Claude Code が使える状態にしておいてください。使い方は2通りあります：
    ・Claude デスクトップアプリ（パソコンにインストールするアプリ）を開いて、左上の 「Code」 に切り替える　←ふだんはこちらが簡単です
    ・または ターミナル（Macは「ターミナル」アプリ／Windowsは「Windows Terminal」）で claude と打って起動する
  • Mac の方：そのまま進んでOKです。
    「動画編集」スキルも使いたい場合のみ、先に Homebrew を入れておくと途中で止まりません（入れ方は下の折りたたみを参照）。分析・台本スキルだけなら不要です。
  • Windows の方：「Windows Terminal」から claude で起動してください。
    デスクトップアプリの「Code」タブでは、動画編集スキルが動かないことをテストで確認しています（分析・台本スキルはどちらでも動きます）。「Windows Terminal」はスタートメニューで「terminal」と検索すると出てきます（無い場合は Microsoft Store から無料で入ります）。Homebrew は Mac 専用なので、Windows の方は不要です。
🍺 Homebrew の入れ方（Mac で動画編集を使う方だけ・3分）

Homebrew（ホームブリュー）は、動画編集に必要な部品を自動で入れてくれる道具です。1回入れれば、あとはずっと使えます。

① まず入っているか確認：Mac標準の「ターミナル」アプリを開いて、下を貼って実行。バージョン（例：Homebrew 4.x.x）が出たら導入ずみなので何もしなくてOKです。

brew --version

② command not found と出たら、下を貼って実行（公式のインストーラーです）。

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

途中で Macのログインパスワードを聞かれます。打っても画面には何も表示されませんが、そのまま入力して Enter で進みます。数分かかります。

③ 使えるようにする（この2行を忘れると「入れたのに見つからない」となります）。

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile eval "$(/opt/homebrew/bin/brew shellenv)"

④ もう一度 brew --version を実行して、バージョンが出れば完了です。

💡 うまくいかないときは、その画面をスクショして Claude Code に貼り、「これどうすればいい？」と聞けば教えてくれます。

1

マーケットプレイスを登録

おとラボのスキル置き場を Claude Code に教えます。下の1行をコピーして、Claude Code に貼って実行してください。
Claude Code に貼る ①
/plugin marketplace add izzzenk-ops/otolab-skills
2

スキルを一括インストール

全スキルが入った「otolab-insta」を入れます。同じく下の1行を貼って実行してください。
Claude Code に貼る ②
/plugin install otolab-insta@otolab-skills
3

初期設定（あなた専用にする）

最後に、下の文章をまるごとコピーして Claude Code に貼って実行してください。Claude が1問ずつ質問しながら、成果物の保存フォルダとあなたの発信プロフィールを作ってくれます。これで台本・分析スキルがあなた仕様で動くようになります。
Claude Code に貼る ③（全文コピー）
おとラボスキルを使うための初期設定をお願いします。以下を順番に実行してください。 1. ホームの「Documents/Claude/Projects」フォルダを作成する（すでにあればそのまま使う）。今後、分析報告書・台本などの成果物はすべてこの中に保存される。 2. 「Documents/Claude/CLAUDE.md」を次の内容で作成する（すでにあれば内容を壊さずにこのルールを追記する）： - 成果物は必ず Projects/<プロジェクト名>/ の中に作る。Documents/Claude の直下にファイルを直接置かない - 一時ファイルはセッションのscratchpadを使い、このフォルダには置かない - ファイルやフォルダの削除・移動は勝手にせず、必ず提案して許可を得てから行う 3. 私に1問ずつ質問しながら「Documents/Claude/Projects/発信プロフィール/profile.md」を作成する。聞いてほしい項目： - 名前（ニックネームOK） - Instagramのアカウント名（まだなければ「これから」でOK） - 発信ジャンル - 誰に向けて発信するか（ターゲット） - 発信の目的（フォロワーを増やしたい・集客につなげたい など） - 口調・キャラの希望（あれば） 回答を profile.md にきれいにまとめて保存する。 4. 最後に、作成したフォルダ構成をツリーで見せて「初期設定完了」と報告する。
💡 次回から Claude Code を開くときは、作業フォルダに「Documents/Claude」を選ぶと設定が効きます。

🎉 これで完了です

スキルが増えたら（更新の受け取り方）

おとラボのスキルはあとから増えたり、改良されたりします。すでに導入ずみの方は、下の1行を貼って実行するだけで最新の状態になります（入れ直す必要はありません）。うまくいくと「更新しました」と表示されます。
Claude Code に貼る（更新したいとき）
/plugin marketplace update
💡 「新しいスキルを追加しました」と連絡が来たときに実行してください。ふだんは不要です。実行しても、作った成果物や初期設定は消えません。

🎬 「動画編集」を初めて使うときだけ

  • 初回に話しかけると、編集ツールを自動でセットアップします（数分〜十数分／ネット接続が必要。2回目以降は速いです）。
  • Mac の方は先に Homebrew を入れておくと途中で止まりません（上の「はじめる前に」参照）。
  • 途中で許可を聞かれたら 「常に許可（今後聞かない）」 を選ぶとスムーズです。
  • Windows の方は 「Windows Terminal」の claude で使ってください（アプリの「Code」タブでは動きません）。
💬 途中で止まったり、よく分からない画面が出たら —— その画面をスクショして、いま開いている Claude Code にそのまま貼り付けて「これどうすればいい？」と聞いてください。その場で教えてくれます。
