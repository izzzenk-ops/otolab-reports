OTOLAB SKILLS

おとラボ スキル・ツール一覧

Claude Code で使える、インスタ運用＆動画編集のスキル集（全12点）

導入は最初の1回だけ、この2行を Claude Code に打つだけ： /plugin marketplace add izzzenk-ops/otolab-skills /plugin install otolab-insta@otolab-skills
運用の流れ：① 設計 → ② 分析 → ③ 台本 → ④ 編集（この一覧もその順番で並んでいます）
🎯 設計するまずはここから

アカウント設計

insta-concept-design
①自己分析インタビュー →②コンセプト設計（誰の・どんな悩みを・どう解決する）→③アカウント名＆プロフィール作成、の3ステップで発信の土台を固めます。すべての出発点。
起動ワード 自己分析してコンセプト決めたいアカウント名考えてプロフィール作って

コンセプト磨き上げ

concept-brush-up
設計で固めたジャンル・コンセプトを、もっと目立てる・差別化できる形に磨き上げたいときに使います。10案をレポートで出し、対話しながら決定版＋プロフ改善案まで仕上げます。
起動ワード コンセプトを磨きたいコンセプト10案出して差別化できるコンセプト
📊 分析する

リール1本 徹底分析

bunseki-reel
気になるリール1本のURLを渡すと、動画DL・全文文字起こし・画面解析をして、冒頭フック／サムネ設計／構成／台本と型／視聴者心理／コメント反応／自分への活かし方を1枚の報告書にまとめて開きます。
起動ワード このリールを分析してこのリールなんで伸びてるのリールを解剖して＋リールURL

競合アカウント分析

bunseki-competitor-account
参考アカウントを丸ごと分析。伸びてる上位＋最新リールを文字起こしして、サムネの法則・台本の共通構成・伸びてる理由・自分への活かし方をサムネ入り報告書に。
起動ワード 競合分析してこのアカウントを徹底分析してなんで伸びてるのか調べて＋アカウントURL

自分のアカウント分析

bunseki-my-account
スマホのインサイト画面録画を渡すと、裏側データ（外部リーチ・視聴維持率・保存率）×投稿の中身を突き合わせ、伸びなかった原因診断・冒頭文5案・次に作る10本リストまで出します。
起動ワード 自分のアカウント分析して自分のインサイト分析して次の施策考えて
✍️ 台本を作る

型移植 台本作成

daihon-copy-make
参考台本や分析結果から「型」を抽出して、自分の出来事を同じ構成・文体・視聴者心理設計の台本に変換。どんな参考でも即席で「その人風」に。
起動ワード この台本を参考に台本を作って〇〇風で今日の出来事を台本にして

台本 辛口添削

daihon-tensaku
できあがった台本テキストを貼るだけで、動画なしで6軸100点採点＋1フレーズずつ解説（感情の動き／改善案／加えるワード）、Before→Afterのリライト完成台本まで。撮影前の最終チェックに使えます。
起動ワード 台本を添削してこの台本どう？台本を採点して
🎬 動画を編集する

アフレコ動画 自動編集

reel-henshu-afreco
アフレコ音声と素材フォルダを渡すだけで、文字起こし→カード生成→素材の自動割り当て→ブラウザの編集画面（テロップ・演出を調整）まで一気に。縦型ショート動画を書き出せます。
起動ワード アフレコ動画を編集して
💡 Mac＝そのまま／Windows＝「Windows Terminal」の claude で使う（現在テスト中）
💡 初回セットアップ時に許可を何度か聞かれます。「常に許可（今後聞かない）」を選べば、以降は聞かれずスムーズに進みます（分析系のスキルではほぼ聞かれません）。

リール完コピ

reel-henshu-copy
お手本にしたい参考リールのURLを渡すと、そのリールと同じ尺・同じカット割りでカードを発行。各カードに自分の素材をはめるだけで、伸びているリールの編集リズムを丸ごと完コピできます。カードの秒数は数字で微調整でき、お手本（そのカットだけ再生）を見ながらワンクリックで分割も可能。素材が未割り当てでも参考映像で仮表示して通しプレビューできるので、途中で詰まりません。
起動ワード このリールを完コピしたい参考リールのカット割りで作りたいリール完コピ
💡 音声（アフレコ）から作るときは上の「アフレコ動画 自動編集」を使います。こちらは音声なし・自分で撮った素材を、伸びているリールの型に流し込む用です（編集画面は共通）。

無音カット

cut-silence
動画・音声の言葉と言葉の間（無音）を自動で見つけてカットし、テンポのいい素材に短縮します。しゃべっていない“間”が詰まるので、ダラっとした動画が一気に見やすく。出力は元と同じフォルダに 元の名前_cut.mp4（音声だけなら _cut.m4a）で保存され、元ファイルはそのまま残ります。
起動ワード 間をカットして無音をカット動画を短くしてジャンプカットして
💡 Apple Silicon Mac 専用。初回だけ ffmpeg が必要で、入っていなければ入れ方を案内します（1回入れれば以降は不要）。
✨ 応用編：好きな発信者の“型”を移植する（事例集）
ここは基本スキルではなく、「使い方の応用例」です。
まず 競合アカウント分析 で、お手本にしたい発信者（自分のロールモデル）を徹底分析 → その人の口調・言い回し・構成を自分の台本に移植する、という使い方ができます。下の2つは、その代表例（特定の発信者スタイルを再現するテンプレ）です。

大阪弁 1日Vlog台本応用

daihon-kyaba-vlog
その日の出来事を話すと、大阪弁・一人称の等身大な実況ナレーションの1日Vlog台本に変換。※特定の発信者スタイルの再現例です。
起動ワード vlog台本書いて1日Vlogの台本作って今日あったことで台本書いて

映画風 Vlog台本応用

daihon-eiga-vlog
その日の出来事を、映画・ドキュメンタリーのナレーター文体（三人称・皮肉・官僚語）のVlog台本に変換。※特定の発信者スタイルの再現例です。
起動ワード 映画風台本書いて映画風にして
