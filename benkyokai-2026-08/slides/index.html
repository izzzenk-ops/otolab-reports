01 ｜ WHAT IS CLAUDE CODE

Claude Code ＝ あなたのPCの中で作業してくれる Claude

💬

ふだんの Claude（チャット）

質問に「答えてくれる」。
文章のアドバイスや相談が得意。
でも、あなたのPCの中は触れない。

🛠️

Claude Code

話しかけると「作業までしてくれる」。
動画をダウンロードして文字起こしして、
報告書を作ってブラウザで開く——まで全部。

使い方は同じ。日本語で話しかけるだけです。

01 ｜ WHY

インスタ運用の「めんどくさい」が全部1か所に

📊

分析

伸びてるリールをダウンロード→全文文字起こし→なぜ伸びたかを報告書に。手作業なら数時間の作業です。

✍️

台本

参考発信者の「型」を抽出して、あなたの出来事を同じ構成の台本に。添削・採点までしてくれます。

🎬

編集

アフレコ音声と素材を渡すだけで、テロップ付き縦型動画に。参考リールの完コピ編集も。

これを実現するのが、おとラボの「スキル」です。

01 ｜ SKILLS

「スキル」＝ Claude に渡す専用レシピ

スキルなし

「リール分析して」と頼んでも、毎回やり方がバラバラ。手順の説明から始める必要があります。

スキルあり

おとラボで磨き込んだ手順書がClaudeに入っているので、起動ワードを言うだけで、毎回同じ品質の報告書・台本・動画が出てきます。

このリールを分析して＋URL 今日あったことで台本書いて アフレコ動画を編集して ← こういう「起動ワード」で呼び出します
02 ｜ PREPARATION

はじめる前のチェック

  • Claude Code が使える状態（デスクトップアプリの「Code」モード、またはターミナルの claude）
  • Chrome に Claude 拡張機能（アカウント分析でインスタ画面を見るのに使います）
  • Chrome で Instagram にログイン済み
  • （Macで動画編集も使う人だけ）Homebrew — brew.sh から。分析・台本だけなら不要
02 ｜ 先に言っておきます

ここでつまずく人が多い2つ

①

デスクトップアプリと
ターミナルの claude は別物

アプリを入れても、ターミナルで claude は使えるようになりません（逆も同じ）。

「貼るだけ」で進めない＝あなたのせいではありません。
ターミナル版を入れるなら1行でOK：

curl -fsSL https://claude.ai/install.sh | bash

Windowsは irm https://claude.ai/install.ps1 | iex
入れたらターミナルを閉じて開き直す

②

レポートが出てくる場所は
ここで固定

分析レポートも台本も、どのフォルダから起動しても必ずここに保存されます：

書類 → Claude → Projects

デスクトップに「Claude」フォルダを作って使っている人もそのままでOK。スキルは正常に動きます。

探すときだけ「書類」を見てください。

💡 どちらも実際に出た質問です。今日この場で全部解決します。

02 ｜ INSTALL

導入は、この2行をコピペするだけ

① マーケットプレイスを登録（おとラボのスキル置き場を教える）
/plugin marketplace add izzzenk-ops/otolab-skills
② スキルを一括インストール（全16スキルが一度に入る）
/plugin install otolab-insta@otolab-skills

🎉 最初の1回だけでOK。次のスライドから、いま全員でやります。

02 ｜ WORK TIME（15分）

🖐 いっしょにやってみよう

  1. Claude Code を開く（アプリの「Code」モード、またはターミナルの claude）
  2. 1行目 /plugin marketplace add izzzenk-ops/otolab-skills を貼って実行
  3. 2行目 /plugin install otolab-insta@otolab-skills を貼って実行
  4. 配布した「初期設定プロンプト」を貼って実行 —— Claude が質問しながらあなた専用の設定を作ります
  5. 「初期設定完了」が出たらゴール🎉 早く終わった人は、隣の人を助けてあげてください

🆘 途中で変な画面が出たら —— その画面をスクショして Claude Code に貼り付けて「これどうすればいい？」

初期設定で、あなた専用の作業場ができました

💡 次回からClaude Codeを開くときは、作業フォルダに「Documents/Claude」を選ぶとルールが効きます

05 ｜ TIPS

つまずきやすいポイント

  • 動画編集の初回だけ：編集ツールを自動セットアップします（数分〜十数分・ネット必要）。2回目以降は速いです。
  • 許可を聞かれたら：「常に許可（今後聞かない）」を選ぶとスムーズ。分析系ではほぼ聞かれません。
  • Windows の方：「Windows Terminal」の claude で使ってください（アプリの「Code」タブでは動画編集が動きません）。
  • スキルが更新されたら：Discordでお知らせします。/plugin marketplace update を1回実行するだけ。
05 ｜ HELP

困ったときの魔法の一手

分からない画面が出たら、その画面をスクショして
Claude Code に貼り付けて「これどうすればいい？」

エラーの意味を調べる必要はありません。Claude がその場で解決してくれます。
